🤖 Aha Chat Widget Integration Example

This page demonstrates how to integrate the Aha Chat widget into your website. The widget will appear as a floating button in the bottom-right corner.

Note: This is a demo page. In a real implementation, you would replace the placeholder values with your actual webchat configuration.

Integration Steps

  1. Create a webchat in your Aha Chat dashboard
  2. Add your domain to the authorized domains list
  3. Copy the embed code from the webchat management page
  4. Paste the code into your website's HTML

Basic Integration

Add this code to your website's HTML, typically before the closing </body> tag:

<!-- Aha Chat Widget --> <script> window.AhaChatConfig = { // Optional: Override default settings // brandColor: '#007bff', // hideHeader: true, // showLogo: false, // hideMessageInput: true }; </script> <script src="YOUR_BASE_URL/api/webchat/embed/YOUR_WEBCHAT_ID"></script>

Advanced Configuration

You can customize the widget appearance and behavior by modifying the AhaChatConfig object:

<script> window.AhaChatConfig = { brandColor: '#ff6b6b', // Custom brand color hideHeader: true, // Show/hide header showLogo: true, // Show/hide personal logo hideMessageInput: true, // Show/hide message input // Add more customizations as needed }; </script>

Security Considerations

Important: The widget will only work on domains that are authorized in your webchat configuration. Make sure to add your domain to the authorized domains list in the Aha Chat dashboard.

Testing the Widget

To test the widget on this page, you can:

  1. Replace YOUR_BASE_URL with your actual Aha Chat base URL
  2. Replace YOUR_WEBCHAT_ID with your actual webchat ID
  3. Add this domain to your webchat's authorized domains
  4. Refresh the page to see the widget in action
